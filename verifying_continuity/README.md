# Verifying continuity

The code in this section is used to verify that $\Xi \circ \Psi$ is well-behaved.
The necessary layer definitions and the simple composition architecture are found in [`network_def.py`](network_def.py), while [`run_test.py`](./run_test.py) is the script to actually run the experiment. 
Each of the subfolders of [experiments](./experiments) contains the config file(s) and bash scripts to actually run the given experiment, as well as log files and output results.
